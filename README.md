## Demo: https://webcademy.netlify.app/

### Edit 21 November 2025: I continue to receive numerous messages requesting an update to this repository, but I don't have the capacity to provide one. However, you can use [Builduo](https://builduo.com/) for the backend and [Lovable](https://lovable.dev/) or [Bolt](http://bolt.new/) for the frontend.

Firebase is great for the backend, but it gets messy very fast. Builduo is a great alternative you can use to vibe code the backend and get it up and running within minutes.

Built with Firebase and React.

Test built with Puppeteer framework and Mocha.


### Note: This is a quick prototype of LMS built with React. Please expect some bugs and most stylings were done inline for quick testing. PR request is accepted!
